版本、撤销与数据安全 · Ctrl+Z 撤销，Ctrl+Y 或 Ctrl+Shift+Z 重做。
· 「🗂 版本」可建快照、对比和回滚；新建、载入示例、导入前会自动快照。
· 草稿仍保存在本浏览器；重要项目请同时导出 JSON 文件。API Key 只存在浏览器本地，不进入项目导出。
批量、统计与体检 · 「⚡ 批量」支持全文替换和指定数值批调，操作后可撤销。
· 「📊 统计」查看本浏览器试玩中的场景到达、选项偏好和结局次数。
· 「🩺 体检」检查断链、孤立场景、错误条件和项目体积。
AI 与视频任务 · AI 面板提供 OpenAI、DeepSeek、通义、智谱预设，不覆盖你的 Key。
· 无 API 时可先用校园恋爱、悬疑、分支、多结局等本地灵感模板。
· 视频 API 若返回任务 ID，会自动轮询状态和进度；可点「停止轮询」。
快捷键与常见问题 · 播放器：空格/Enter 继续，Backspace/← 后退，A 自动播放，Esc 返回。
· 编辑器输入框内 Ctrl+Z 保留浏览器原生文字撤销，不会误回滚整个项目。
· AI 报 Failed to fetch：检查 Base URL、网络和服务商 CORS；视频失败可查看任务状态。
· 大量 base64 图片会放大项目体积；体检接近 512KB 时建议使用外链素材并导出 JSON 备份。
