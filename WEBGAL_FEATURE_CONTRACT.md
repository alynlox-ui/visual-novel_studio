# WebGAL-inspired feature contract

Scope: six reference directions; no Steam integration. Preserve legacy behavior by default. New JSON fields:

- `project.director={version:1,templates:[{id,name,version:1,ui,home}]}`. Templates capture merged UI/home; `scene.themeId` and dialogue cue themeId switch player UI only, not authored project.
- `character.portrait={mouthOpen:'',mouthHalf:'',mouthClosed:'',eyesClosed:'',blinkInterval:4000}` on library character. Full-image variants, blink takes precedence; deterministic simulated mouth while text is typing/voice playing is baseline (do NOT claim amplitude analysis). Respect pause. fallback to base/expression. Instance can override portrait.
- `choice.enableCond` supplements existing `choice.cond` (visibility). Empty enabled. `choice.disabledReason` shown when disabled. Recheck in handler; condition failure fails closed.
- `scene.inheritStage={background:false,characters:false,bgm:false}`. When true, retain previous effective stage property; when false reset from authored scene. State stored in saves/history. Initial single-scene preview has no previous stage; provide authoring explicit path preview via entry.
- `scene.flow={mode:'next'|'call'|'return',target:'',returnTo:'',args:{name:value},result:'',value:''}`. Runs after dialogues/choices and before normal next. call pushes caller locals + returnTo + result; args are literal JSON values (no eval), callee locals shadow global flags. return value supports `{name}` interpolation; return writes to caller local if existing else global flag. Max stack 32. Error on missing target/return, not silent. Normal scenes inside subroutine retain locals until return. Save/restore stack+locals.
- `dialogue.cues=[{at:3,type:'expression'|'move'|'theme',target:'instance-id',expressionId:'',themeId:'',x:50,y:88,duration:1000,keep:true}]`. at is revealed UTF-16 character count; apply once when threshold crossed incl instant finish. move x/y are absolute stage percentages; linear interpolation using active playback delta; keep persists across dialogue changes, otherwise snaps to target on next dialogue. New move same target replaces old. Scene entry clears moves unless stage inherited. Pause freezes; rate scales elapsed. Save clock/moves/applied cue state. Expression changes effective instance expressionId. theme switches runtime template.

Implement authoring forms, preview runtime, exported standalone runtime, native runtime, and feature-specific tests. Browser standalone module uses embedded `createDirector.toString()` so no external script needed by exported game. Native source must build with C#5, DTO properties not fields. Existing native audio is implemented; do not remove or disable it.
